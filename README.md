# ⚡ AndreyWidget

Widget nativo para Android (ARM64) diseñado para integrarse con **Termux** y permitir el control de servicios locales (Nginx, Cloudflare Tunnels, entornos de código) directamente desde el escritorio de Android.

## Características

- 🎨 **Diseño Moderno Dark:** Paleta de colores `#0e1320`, bordes redondeados `24dp` y estilos visuales armónicos con interfaces Material / OneUI.
- 🔄 **Sincronización Dinámica:** Auto-descubrimiento de scripts en `$HOME/.shortcuts/` en Termux mediante intents de broadcast.
- 📱 **Paginación Rotativa:** Navegación por páginas (`◀ 1/X ▶`) para organizar múltiples scripts y servicios sin sobrecargar la pantalla.
- 🔒 **Sin conflictos de firma:** No requiere `sharedUserId`, se comunica mediante la API oficial `com.termux.permission.RUN_COMMAND`.
